#  After-Care Portal Frontend
A modern web application designed to digitize Sri Lanka's death registration and post-death service workflow. This system enables families and government officials to manage the entire process—from initial case reporting to final certificate issuance—through a secure and streamlined digital platform.

---

##  Features
- **Role-Based Access Control** (Family, GN, Doctor, Registrar)
- **Digital Document Workflow** (B-24, B-12, B-11, B-2)
- **Automated Case Progression**
- **Real-Time Case Tracking**
- **Secure Authentication & Data Handling**
- **Responsive, Mobile-Friendly UI**

---

##  Overview
The application replaces a traditionally manual, paper-based process with a structured digital workflow:

```
Family → GN Verification → Medical Certification → Registrar Approval → B-2 Issued
```

It focuses on improving efficiency, transparency, and user experience during a sensitive and critical process.
